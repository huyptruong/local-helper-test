# OC Rec Finder

A responsive React prototype for comparing sample public recreation programs across five Orange County cities.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm test`, `npm run lint`, and `npm run build` for verification.

All 25 listings are illustrative sample data. Program availability, dates, fees, and schedules are not live; users should verify details and register on the linked official city website.
